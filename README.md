# 🌴 Website WisataKeren - Jelajahi Keindahan Dunia

Website **WisataKeren** adalah platform landing page modern yang dirancang untuk mempromosikan destinasi wisata dengan estetika visual yang bersih dan interaktif. Proyek ini dibangun untuk menonjolkan keindahan alam, khususnya dengan sentuhan identitas dari Papua.

---

## ✨ Fitur Utama
* **Hero Section Modern**: Tampilan visual penuh dengan efek overlay teks yang elegan untuk menarik perhatian pengunjung.
* **Mode Gelap/Terang (Dark/Light Mode)**: Fitur switch tema otomatis/manual untuk kenyamanan visual pengguna.
* **Desain Responsif**: Optimasi penuh sehingga website tampil sempurna baik di desktop maupun perangkat mobile.
* **Integrasi Media Sosial**: Akses cepat ke WhatsApp, TikTok, dan Instagram melalui tombol interaktif.
* **Scroll Reveal Animation**: Elemen website muncul secara halus saat pengguna melakukan scrolling halaman.

---

## 🛠️ Teknologi yang Digunakan
* **HTML5**: Struktur web semantik untuk performa dan SEO yang lebih baik.
* **CSS3**: Menggunakan *Custom Properties* (Variables) dan Flexbox untuk tata letak yang fleksibel.
* **JavaScript (Vanilla)**: Menangani logika untuk toggle Dark Mode dan kontrol animasi halaman.
* **Font Awesome**: Digunakan untuk ikon-ikon media sosial yang modern dan clean.

---

## 📂 Struktur & Penjelasan Kode
Berdasarkan susunan file `index.html`, berikut adalah alur komponen website ini:

1.  **Header & Navigation**: 
    * Logo "WisataKeren" dengan navigasi menu (Beranda, Tentang, Galeri, dll).
    * Terdapat tombol khusus di sisi kanan untuk mengganti tema (Dark/Light).
2.  **Hero Section**: 
    * Berisi slogan utama "Jelajahi Keindahan Dunia" dengan latar belakang gambar destinasi wisata berkualitas tinggi.
    * Tombol "Mulai Penjelajahan" sebagai *Call to Action* utama.
3.  **Social Media Section (Line 220)**: 
    * Bagian khusus dengan class `social-icons reveal` yang menghubungkan pengunjung ke akun TikTok, Instagram, dan WhatsApp pengembang.
4.  **Footer (Line 262)**: 
    * Informasi hak cipta dan identitas pengembang.
    * Lokasi operasional: **Papua Tengah, Nabire, Indonesia**.
5.  **Scripting**: 
    * Pemuatan `script.js` di bagian akhir untuk memastikan performa loading website tetap cepat.
